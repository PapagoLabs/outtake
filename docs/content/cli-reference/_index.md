Complete command reference for outtake, generated from the program itself.

outtake creates video clips, GIFs, and screenshots from your Plex media server.

## Commands

| Command | Description |
| --- | --- |
| [health](/cli-reference/health/) | Check the health of the outtake server |
| [owner reset](/cli-reference/owner/reset/) | Forget the owner so the next Plex account to sign in claims outtake |
| [server start](/cli-reference/server/start/) | Start the outtake server |
| [version](/cli-reference/version/) | Print the application version |
