Check the health of the outtake server

## Usage

```bash
outtake health
```

## Options

| Flag | Short | Default | Type | Description |
| --- | --- | --- | --- | --- |
| `--listen` |  | `""` | string | Listen address, which overrides OUTTAKE_LISTEN_ADDR |
